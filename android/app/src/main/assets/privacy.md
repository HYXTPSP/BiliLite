# 《BiliLite》隐私政策

**更新日期：2026-08-26**
**生效日期：2026-09-01**

## 引言

欢迎使用BiliLite（以下简称"本软件"）。本软件由湍（以下简称"我们"）独立开发，是一款开源的非官方第三方哔哩哔哩客户端。

我们深知个人信息对您的重要性，并始终秉持"数据本地化、最小处理"的原则。本政策依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》等法律法规制定，如实、完整地列明本软件使用的全部第三方组件、申请的权限、在本地存储的数据及网络交互情况，以及您依法享有的各项权利。

**特别提示**：本软件为纯本地运行的工具，不具备后端服务器，亦不采集、不上传您的个人信息。本政策的制定目的，是如实告知您本软件如何处理（即"基本不处理"）您的个人信息，以及您依法享有的各项权利。

## 一、第三方开源组件清单

本软件使用的第三方组件均为通用开源技术库，**不含任何广告 SDK、统计/埋点 SDK、推送 SDK、地图/定位 SDK、支付 SDK 等收集型组件**。完整清单如下：

| 组件 | 用途 | 是否涉及个人信息收集 |
|---|---|---|
| Jetpack Compose + Material3 | UI 界面框架 | 否 |
| Material Icons Extended | 界面图标 | 否 |
| AndroidX Activity / Lifecycle | 页面生命周期管理 | 否 |
| Room (SQLite) | 本地数据库 | 否 |
| Kotlin 协程 | 异步任务处理 | 否 |
| ZXing core | 登录二维码生成（本地生成，不上传） | 否 |
| Media3 (ExoPlayer) | 视频播放器（含音视频解码、进度控制） | 否 |
| Media3 OkHttp 数据源 | 视频流下载传输 | 否 |
| Coil | 网络图片加载与缓存（封面、头像） | 否 |
| OkHttp | 网络请求底层传输 | 否 |

上述组件的开源协议与来源详见仓库中的 `THIRD_PARTY_NOTICES.md`。

## 二、我们如何收集、存储和使用信息

本软件**不采集、不上传**任何个人信息。下列数据均仅在您的设备本地存储与使用：

| 数据类型 | 存储位置 | 说明 |
|---|---|---|
| B 站登录凭证（cookie，如 SESSDATA 等） | 本地 SharedPreferences | 仅用于调用 B 站接口，不会上传至 B 站官方接口以外的任何服务器 |
| 关注的 UP 主列表 | 本地数据库 | 由您手动添加 |
| 收藏视频列表 + 自定义分类 | 本地数据库 | 含"父/子"嵌套分类 |
| 观看历史与进度 | 本地数据库 | 用于断点续播 |
| 视频书签（时间点 + 备注） | 本地数据库 | 由您手动标记 |
| 离线缓存视频 | 应用私有目录 | 由您手动下载 |
| 运行日志（含请求路径 / 响应码） | 应用私有目录 | 仅用于排查问题，可手动导出 / 清空 |
| 数据备份文件（JSON） | 由您主动导出至指定位置 | 含上述全部本地数据 |

**网络交互**：仅在您主动操作时（刷新、播放、登录、同步）向哔哩哔哩官方域名发起请求：`api.bilibili.com`、`www.bilibili.com`、`passport.bilibili.com`、`aisubtitle.hdslb.com` 等，**不包含任何第三方服务器**。

## 四、我们如何存储和保护个人信息

1. **存储位置**：上述数据仅存储于您的设备本地（应用私有目录），我们不运营任何服务器、不提供任何云存储。
2. **安全措施**：我们参照《个人信息保护法》第五十一条关于采取加密等安全技术措施的要求，对涉及敏感凭证的登录信息，建议采用 Android Keystore 加密机制（如 EncryptedSharedPreferences）进行加密存储，并尽量减少本地数据的暴露风险。
3. **风险提示**：由于数据完全保存在您的设备，您设备本身的安全状况（如是否 root/越狱、是否安装恶意软件等）由您自行负责。建议您使用可信设备并妥善保管账号。

我们**不共享、不转让、不公开披露**您的任何个人信息——因为我们不采集任何个人信息，也不具备向任何第三方提供数据的通道。

本软件不含任何广告、统计分析、崩溃上报、推送等收集型第三方 SDK（详见本政策第一节）。

依据《个人信息保护法》第四十四条至第四十八条，您对您的个人信息享有以下权利。由于本软件不采集个人信息，这些权利通常可通过您在本软件内的操作直接实现：

1. **知情权、决定权（第四十四条）**：您可随时查看本政策，并自主决定是否登录、是否导出日志或备份、是否继续使用。
2. **查阅、复制权（第四十五条）**：本软件涉及的信息（登录凭证、本地数据、日志）均存储在您的设备上，您可直接查看；如导出日志或备份，可复制其内容。
3. **更正、补充权（第四十六条）**：您可通过重新登录、编辑列表、清除数据等方式更正或更新本地保存的信息。
4. **删除权（第四十七条）**：您可随时退出登录、清空缓存、清除应用数据或卸载软件，即可删除本地保存的全部凭证与数据。
5. **要求解释说明权（第四十八条）**：如对本政策的处理规则有疑问，您可通过本政策第十一节提供的联系方式要求我们解释说明。

## 七、未成年人保护

本软件不采集任何个人信息，因此不涉及未成年人的个人信息收集。

尽管如此，我们特别提示：根据《个人信息保护法》第三十一条，任何组织处理不满十四周岁未成年人的个人信息，应当取得其父母或者其他监护人的同意。鉴于本软件不处理未成年人的个人信息，我们不区分用户年龄；如您是未成年人，请在监护人指导下使用本软件，并妥善保管账号。
